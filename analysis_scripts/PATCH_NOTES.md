# 本批实现与基座修正

原始base/class脚本逐字保存在99_original。以下是本项目适配，不修改服务器上其他项目使用的轮子。

## 直接修正的原脚本

- 默认不自动安装包，由环境检查和用户安装命令负责。
- class按项目脚本目录加载base，避免source嵌套时误判路径。
- edgeR保留原GLM/LRT路线；平均标准化CPM另存baseMean，不覆盖logCPM。
- MA图使用正确baseMean；ggmaplot的fc参数传入2^logFC阈值，避免其内部log2变换导致阈值错误。
- 显著DEG与火山图的效应阈值统一为>=；阈值由项目入口显式提供。
- 排序图与MA图使用独立文件名，不覆盖火山图。
- 箱线图按字符样本名关联分组，避免factor整数索引导致错配。
- 相关热图可控制是否显示数值，避免重复参数及密集数字。
- 四风格PCA使用同一坐标；椭圆只用于满足最低样本数的组。
- 方向配色统一，主要绘图标签使用英文；PDF优先使用cairo设备。

## 兼容层修正

- 以R6生成器set接口替换出错的GTF/gene2go加载方法，保留原数据对象和接口体系。
- gz GTF先解压到临时文件；gene2go按块读取，适配NCBI标准列，不要求Symbol。
- 注释缓存保存输入路径、大小、修改时间和基因范围；GO按tax_id/GeneID过滤NOT，证据类型保留。
- GO背景仅BP，可统一传播到BP祖先条目；不把CC/MF混入BP图。
- KEGG使用KEGGREST与物种缓存；本地GO注释加载不依赖网络预检成功。
- ORA统一ENTREZID、显著DEG前景与明确受检背景；上调/下调分别计算。
- GSEA使用全部有效受检基因；串行执行，保存原始结果对象和排序列表。
- 富集原始计算对象不直接改成SYMBOL；图上标签单独映射。
- 四类比较绘图接口仍保留，但读取已计算富集结果，不重跑差异分析，不使用旧缓存串比较范围。
- 比较图横轴保留9个比较；ORA的Up/Down轻微错开，防止覆盖。
- 旧主题热图改接当前DEG、标准化表达和GO映射；缺失值保持NA，不伪装成零效应。
- 原ORA网络包装处于注释状态，本批恢复为项目辅助函数；Venn/UpSet/花朵图补齐返回对象，便于组合。

## 可选项目的边界

本批包含规划中的主要原有图型和组合方式。GSVA/ssGSEA、山脊图、条目相似性网络/树图、算法敏感性分析及时间交互模型仍为可选扩展，没有默认执行。

Pathview需要独立包与KEGG通路图网络访问；无包或下载失败会记录状态。GSEA曲线默认每比较Top3，可调节，但完整结果表不截断。
